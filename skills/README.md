# Project Skills (Garden Skills)

Imported verbatim from https://github.com/ConardLi/garden-skills (MIT, see `LICENSE-garden-skills`).
Any AI assistant working on Clinexus MUST use these skills. Before a matching task, read the skill's `SKILL.md` in full and every reference file it routes to, then follow its workflow exactly.

| Skill | Use it when the task involves |
|---|---|
| `web-design-engineer/` | Any UI, layout, styling, page, component, visual or redesign work (always use this copy, not `docs/design-skill/`) |
| `beautiful-article/` | Blog posts, articles, long-form content pages, tutorials |
| `gpt-image-2/` | Generating or prompting images, illustrations, social/marketing visuals |
| `motion-showreel/` | Animations, motion design, product showreels |
| `web-video-presentation/` | Web-based slide decks, video-style presentations, demos |
| `kb-retriever/` | Searching/answering from a knowledge base or docs |

Rules: never skip a skill's checklist; when skills overlap, apply all that match; project rules in `AGENTS.md` override only where they conflict.
